Keyenv Personal隐私政策使用说明与条款

Keyenv Personal

Keyenv Personal 是个人使用的本地命令行密钥管理工具，帮助你在自己的设备之间同步加密的 API 密钥、token 和配套配置，并向你明确选择的程序注入环境变量。

如何使用 Google Drive

你通过现有 Desktop OAuth 客户端授权，仅请求 https://www.googleapis.com/auth/drive.file。程序核对授权账号，将封装的数据密钥和加密版本文件保存在明确绑定的 Keyenv 文件夹中。权限可用于应用创建或你明确授权的文件，不代表严格的单文件夹权限。

本机解锁与登录

主密码由你保管，仅在本机终端隐藏输入，程序不保存主密码。首次配置后，本机私有目录保存解锁数据密钥，使后续命令无需重复输入。Google 登录令牌在本机加密保存并自动刷新，不使用系统钥匙串。

当前状态

这是个人使用的开发工具；文件格式仍需长期兼容性和独立评审。请保留独立加密备份。程序无法替你撤销服务商密钥，也无法在主密码和本机解锁材料均丢失后恢复密文。
