# v2 认证与撤销边界

状态：实施中，尚未完成生产验收。v2 bootstrap 凭据不代表旧 Actor；服务端每次业务调用重新检查账户、凭据家族、客户端登记、安装、挂载和助手策略。挂载无单独业务 ACL。账户控制操作使用本人会话和 CSRF；批准申请同时核对策略版本。

控制库和密钥库是独立 D1 数据库，无法共同原子提交。密钥调用读取控制库的当前权限，并在重要操作前重查；密钥库的策略缓存只允许版本递增。策略收紧或撤销在之后的授权检查生效，但已经通过检查并在执行中的请求仍可能完成。不能宣称跨库撤销与在途写入是原子的，也不能保证已经取得的秘密可追回。

本地 SQLite 覆盖 PKCE、刷新重放、权限收紧、批准重放和路由失效；它不能替代真实 D1 并发、真实账户登录、客户端宿主和生产迁移验收。不能因为旧独立服务退役而清空当前统一服务的数据库。

OAuth 家族撤销或刷新令牌重放导致家族撤销时，如果该安装已没有其他未撤销且未过期的家族，服务端在同一控制库批处理中撤销挂载、将已分配或已领取投递转入待交接，并为失效默认会话选择其他有效挂载上的会话；没有候选时默认留空。旧会话与投递历史保留。重新接入会产生新的安装身份，应向原助手提交新的挂载申请并由账户批准，再注册新工作会话；不会靠设备名或旧会话地址自动恢复身份。自然到期或客户端登记失效的后台路由清理和真实 D1 并发仍需验收。
