# Frontend review · 2026-10-31

依据：用户本轮反馈、仓库根 AGENTS.md、主任务本轮读取的 Anthropic 官方 frontend-design skill、已导入的 baoyu-design Miles Works 视觉系统。保留已认可颜色与字体，不为技能示例换主题。

| 发现 | 修改 | 验证 |
|---|---|---|
| 概念说明重复出现在页副标题、右侧卡片和页脚 | 删列表/发消息/收件箱解释侧栏及重复intro，仅保留影响当前决定的范围或恢复说明 | 人工看助手、会话、权限和bridge截图 |
| 名称上方重复品牌eyebrow，辅助口号不服务当前操作 | 删除eyebrow、字标副口号、概念页脚；标题采用统一字号/字重/颜色 | JSX无产品eyebrow元素，人工看截图 |
| 每个实体都是独立圆角卡片 | 助手改同一列表中的行；会话用纵向行和真实分隔，默认设置不再套独立卡片；客户端作为独立关系分组保留面板 | 桌面/手机截图 |
| 正常会话管理出现模拟离线、恢复、注册按钮 | 移入默认折叠的原型演示工具，页面只保留自动上报状态和用户设置 | targeted test检查正常section按钮不含模拟或注册 |
| 收件箱和bridge出现手动模拟领取、推进成功 | 全部移到原型演示面板；正常页面只显示事件结果与异常 | targeted test检查普通按钮，unknown仍阻止自动重试 |
| 独立接入应用tab混合登录、账户和挂载 | 删除tab，右上账户菜单，独立登录页，挂载在助手详情内就地确认 | 导航/独立登录/上下文挂载断言 |
| 移除按钮过度强调、与删除宿主对话易混淆 | 行内使用普通次级按钮；确认框再用危险按钮，明示只移除MW注册 | 确认内容检查 |
| 权限checkbox标签分离 | 维持整行点击、左勾选右文字、44px目标；必要密钥范围与撤回限制保留 | 历史polish检查＋新截图 |
| 解绑/候选选择需要实际后果，不能只toast | 保留会话接收资格变化、替补/留空、未完成任务交接、done/unknown保持，以及具体候选能力 | 既有targeted checks与现行交互；不冒称真实后端验证 |
| 技术依赖挤进普通界面 | OAuth scope升级候选只写DESIGN；bridge实例ID置技术详情折叠；普通挂载只说明范围和设备待确认 | 人工阅读主流程 |

接收阶段编号保留：它代表保存→通知→领取→回执的真实先后顺序，不是装饰编号。正常UI无标题单词局部变色、全大写装饰标签、渐变或入场动画。
